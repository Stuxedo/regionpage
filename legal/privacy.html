Privacy Policy

Effective: October 2026

The short version

This is a plain static HTML page that introduces a Stuxedo region and lists the servers in it, hosted on GitHub Pages. There's no server-side code, no database, no account system, and no forms of any kind — so there's nothing for us to collect.

This website

There is no email signup, newsletter, contact form, or any other way to submit information on this page — nothing is sent to us through the page itself.

The Exo 2, Barlow and Inter fonts are served from this same domain, not a third-party CDN. Three things are loaded from outside this domain: the logo and icon images, from global.media.stuxedo.com (infrastructure operated by the same Stux Group Ltd chain that runs this page); the flag icons stylesheet and flag images, from cdnjs.cloudflare.com; and the live server status, read from raw.githubusercontent.com (GitHub), where the Stux.Group status page publishes it. Like any web host, those services can see your IP address and browser details when your browser asks them for a file; we don't receive or store any of that.

localStorage

The only thing this page stores in your browser is a single value, stuxedo-theme, remembering whether you last chose light or dark mode. It never leaves your device, isn't sent to any server, and can be cleared any time via your browser's site data settings.

How the region is worked out

This page reads document.referrer — the address of whichever page embedded it in an iframe — purely inside your own browser, to work out which region's website is showing it (the first part of that address, such as uk). It also reads a ?region= value if one is in the page's address. Neither value leaves your device or gets sent to us; they're only used locally to choose which region to show.

Links to other pages

This page's logo, the region links and the live status note link out to Stuxedo region websites and to the Stux.Group status page. Each of those may have its own logging or data handling, described on that page rather than here.

Children's privacy

This page isn't directed at children, but since it collects no personal information from anyone, there's nothing specific to say beyond that.

Changes to this policy

If this page grows features that collect data, this policy will be updated first to reflect exactly what's collected and why. The date above marks the most recent revision.
